# 🎙️ Voice Assistant

A simple desktop Voice Assistant developed using **Python**. It recognizes voice commands and performs various tasks such as playing YouTube videos, searching Wikipedia, opening websites and applications, checking the time and date, and performing basic system operations.

---

## 📌 Features

- 🎤 Recognize voice commands
- 🔊 Respond using text-to-speech
- 🤖 Voice assistant named Olly
- ▶️ Play songs and videos on YouTube
- 🕐 Display current time
- 📅 Display current date
- 📖 Search information using Wikipedia
- 🌐 Open YouTube, Google, and GitHub
- 🔎 Search Google using voice commands
- 📺 Search YouTube using voice commands
- 📝 Open Notepad
- 🧮 Open Calculator
- 💻 Open Command Prompt
- 🔄 Restart the computer
- ⏻ Shutdown the computer
- ❌ Stop or exit the voice assistant
- ⚠️ Error handling for speech recognition and network issues

---

## 🛠️ Technologies Used

- Python 3
- SpeechRecognition
- Edge TTS
- Pygame
- PyWhatKit
- Wikipedia
- PyAutoGUI
- Webbrowser

## 🚀 Installation

### 1. Clone the repository

```bash

git clone https://github.com/byteMaster-Soyel/OIBSIP.git
```

### 2. Go to the project folder

```bash
cd OIBSIP/Python-Task1-VoiceAssistant
```

### 3. Install the required package

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
python voice_assistant.py
```
